# 数智健康 OPC 国际人才社区 Web Presentation 页面实施规格 V0.4

> 本文件是后续页面制作的**实施约束**，不是仅供参考的设计说明。HTML、CSS、SVG、交互实现必须逐屏遵循本文件；如需调整业务内容，先修改本规格并形成新版本，再修改页面。

## 0. 全局实施约束

### 0.1 内容基线
- 业务基线：《数智健康OPC国际人才社区在线平台产品功能架构 V0.1》。
- 汇报内容基线：20 屏产品增强版页面方案。
- 核心主线：为什么建 → 平台是什么 → 谁来用 → 平台有什么 → 核心业务怎么跑 → 关键功能怎么实现 → 一期建什么 → 建成后带来什么。
- 产品定位：数智健康 OPC 人才与产业协同平台；不是单纯官网、在线教育平台或项目撮合平台，而是社区业务运营平台。

### 0.2 视觉与布局
- 设计基准：1920×1080；每屏固定 `100dvh`，禁止单屏纵向滚动。
- 安全区：左右 88px；顶部 68px；底部 60px。
- 主体可用区：约 1744×900；默认 12 列 Grid，列间距 24px。
- 标题 42–52px；关键数字 48–72px；正文 17–21px；卡片文字 15–18px。
- 每屏原则：1 个核心观点 + 1 个主体图形/产品 UI + 3–6 个辅助信息点。
- 深浅背景按节奏使用：01深、02浅、03浅灰绿、04米白、05深、06浅、07深、08浅、09米白、10浅灰绿、11深、12浅产品UI、13米白、14深、15浅+场景、16浅后台、17深数据网络、18米白、19浅、20深。

### 0.3 视觉语言
- 风格：现代国风 × 数智科技 × 人才社区。
- 主色：深色背景 `#0C1714`；深墨绿 `#16372E`；本草绿 `#3F8069`；青绿 `#62B99C`；AI蓝 `#51B9DB`；暖金 `#C8A46A`；浅米 `#F3F5F0`；主文字 `#16221E`；辅助文字 `#66736E`。
- 暖金仅用于高级人才、认证、优秀成果、基金、关键数字。
- 中医药元素：本草植物线稿、药材纹理、叶脉、淡山水线条；禁止古风堆砌。
- AI元素：知识网络、节点、流线、智能匹配；禁止机器人/赛博朋克滥用。
- 人才元素：头像、能力标签、成长路径、导师/企业/人才关系网络。

### 0.4 交互原则
- 交互必须帮助理解业务；禁止纯炫技。
- 页面进入：淡入 + Y 轴 20px + 轻模糊解除，650ms 左右。
- 章节页（05/08/18）：背景先切换，主视觉缩放进入，内容依次出现，900ms 左右。
- 核心结构页（06→07）：尽量使用元素重组/位置迁移，避免整页简单 Fade。
- 支持键盘 ↑↓ / PageUp PageDown / 空格切屏；滚轮有节流；右侧显示章节进度。

### 0.5 严禁项
- 不得把页面方案压缩成“标题 + 3 张通用卡片”。
- 不得自行删减“必须出现项”。
- 不得为了视觉简洁改写业务语义。
- 不得用大面积装饰图替代产品结构、流程或 UI。
- 不得使用虚构的真实运营数据；演示分值/进度必须明确标注“示意”。

## Screen 03｜平台需要解决什么
**页面目的**：把建设必要性转化为五类业务问题。

**固定文案**
- 标题：`从“建社区”到“运营社区”，需要解决五个核心问题`

- 培训：`学习如何转化为真实能力？` / `课程、实训与真实产业项目如何连接？`
- 企业：`真实项目从哪里来？` / `企业的数字化诉求如何进入社区并形成标准项目？`
- 项目：`项目如何真正交付？` / `如何揭榜、撮合、执行、验收和沉淀？`
- 孵化：`项目完成以后怎么办？` / `优秀人才和成果如何进一步形成OPC和创业项目？`
- 中央结论：`一套统一的线上平台` / `承载人才、课程、需求、项目和孵化全过程`

**布局**
- 中心 4 列平台结论；五个问题节点围绕中心呈不对称弧线布局，避免五卡片均分。
- 各节点用图标/简化人物与业务符号区分。

**交互**：Hover 任一问题，对应中心连接线和后续能力词高亮。
**禁止**：五张完全相同卡片平铺。

## 21. 全量 QA 规则
每一屏完成后必须逐项检查：
1. **内容完整性**：固定文案与必须出现项不得遗漏。
2. **结构一致性**：必须按照本规格规定的主布局，不得随意改成通用卡片。
3. **一屏适配**：1920×1080、1440×900、1366×768 三档检查，无纵向滚动。
4. **视觉层级**：标题、核心观点、主体图形、辅助信息清晰分级。
5. **间距对齐**：12列 Grid，对齐误差控制在 4px 以内的视觉容差。
6. **初始状态**：无需点击也必须是完整、好看的汇报画面。
7. **交互有效**：交互只增强理解，不能隐藏关键内容。
8. **数据真实性**：无来源数据不虚构；示意数据必须标注。
9. **产品一致性**：人才、项目、课程、需求、状态、标签等组件使用统一 Design System。
10. **视觉节奏**：深浅背景与摄影/产品UI/架构图比例符合全局规则。
