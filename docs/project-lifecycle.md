# Project Lifecycle

Web Presentation 项目统一按以下阶段推进：

1. Planning：资料理解、目标确认、内容架构；
2. Design：视觉基线、关键页面、交互方案；
3. Building：全量页面实现；
4. QA：1920×1080 实渲染、布局与资源检查；
5. Release：Standalone、ZIP、Contact Sheet、审计文件与版本发布；
6. Revision：基于既有基线进行定向修订；
7. Archived：停止维护但保留历史发布。

项目当前阶段写入 `.project/project-state.yaml`，仓库级汇总写入 `PROJECTS.md`。
