# Naming Conventions

## Project slug

使用小写英文和连字符，例如：`opc-talent-community`、`medical-ai-pilot`。

## Version

项目版本使用 `vMAJOR.MINOR.PATCH`，例如 `v0.4.1`。不同项目的版本相互独立。

## Screen

页面编号使用两位数字：`01`、`02`、`03`。

## Release paths

统一使用：`projects/<project-slug>/release/<version>/`。

## Assets

资源文件名应描述用途，避免 `final2-new-last.png` 等不可维护命名。
