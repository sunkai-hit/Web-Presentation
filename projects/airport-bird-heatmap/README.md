# 威海机场鸟情动态热力图原型

本项目为“威海机场鸟情探测系统”中的关键屏交互原型，重点验证**鸟群活动热力图随时间推进动态变化**的展示逻辑。

## 当前成果

- 已完成 2 个原型效果方向，用于确认视觉与信息布局；
- 已完成 1 个可交互关键屏原型；
- 支持时间轴拖拽、自动播放、倍速、区域筛选、风险筛选、重点区域详情；
- 右侧鸟情概况、实时预警、设备状态与当前时间联动刷新；
- 当前使用预置关键帧模拟鸟情时间序列，后续可替换为后端接口或 WebSocket 实时数据。

## 目录说明

- `.project/`：项目状态、内容/视觉基线、页面清单、QA 状态
- `prototype/key-screen-v0.1.0/`：当前关键屏交互原型
- `prototype/README.md`：业务逻辑与交互说明
- `web-presentation.yaml`：项目构建与 QA 配置

## 核心业务逻辑

热力图表达的是某一时间窗口内的鸟群活动密度，而不是单只鸟的瞬时位置。随着时间推进，重点区域内鸟群活动中心会发生迁移，同时热区半径、强度和风险等级变化，并联动右侧统计和预警信息。
