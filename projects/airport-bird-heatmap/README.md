# 威海机场鸟情动态热力图原型

本项目为“威海机场鸟情探测系统”中的关键屏交互原型，重点验证**鸟群活动热力图、移动轨迹与时间回放联动**的展示逻辑。

## 当前版本：v0.1.1

- 已完成鸟群活动热力图随时间动态变化；
- 已新增鸟群移动轨迹：展示各活动中心近 4 小时历史路径、移动方向和尾迹；
- 轨迹颜色与风险联动：高风险偏红、中风险偏橙、普通轨迹为蓝青色；
- 支持轨迹显示/隐藏；
- 支持时间轴拖拽、自动播放、倍速、区域筛选、风险筛选、重点区域详情；
- 右侧鸟情概况、实时预警、设备状态与当前时间联动刷新；
- 已提供模块化版本和单 HTML Standalone 版本。

## 当前原型入口

- 模块化：`prototype/key-screen-v0.1.1/index.html`
- 单 HTML：`prototype/key-screen-v0.1.1/Airport_Bird_Heatmap_V0.1.1_Standalone.html`
- 上一版本：`prototype/key-screen-v0.1.0/`

## 核心业务逻辑

热力图表达某一时间窗口内鸟群活动密度；移动轨迹表达活动中心在时间序列中的迁移路径。随着时间推进，热区中心、范围、强度、风险等级及轨迹同步变化，并联动右侧统计和预警信息。

当前使用预置关键帧模拟真实鸟情数据，后续可将 `frames` 替换为后端时间序列接口或 WebSocket 实时数据。
