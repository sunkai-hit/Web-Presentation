- 鸟群移动轨迹图层：显示当前时刻向前约 4 小时的活动中心移动路径；

- 新增单 HTML Standalone 版本，已内联 CSS 与 JavaScript。

## 业务逻辑

热力图表示某一时间窗口内的鸟群活动密度，而不是单个鸟目标的瞬时位置。轨迹以同一重点区域的活动中心为对象，对历史关键帧进行插值，形成连续路径，用于表达鸟群从栖息/觅食区域向飞行区或其他区域迁移的趋势。

当前轨迹为演示数据。接入真实系统后，建议轨迹数据来源于“鸟群目标/聚类中心 + 时间戳 + 坐标 + 风险等级”的时间序列。
