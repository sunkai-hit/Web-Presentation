# 威海机场鸟情动态热力图原型

## 原型目标

- 以机场地图为主视图，叠加鸟群活动热力图、风险点、探测设备、重点区域标签。
- 支持 06:00–20:00 时间轴拖拽与自动播放，热力中心的位置、范围、强度和风险等级随时间变化。
- 右侧“今日鸟情概况 / 实时预警 / 设备状态”与当前时间联动刷新。
- 支持区域筛选、风险等级筛选、重点区域点击查看详情。
- 原型保持 16:9 单屏展示，不依赖外部 JS/CSS/地图服务。

## 业务逻辑

热力图表示某一时间窗口内的鸟群活动密度，而不是单个鸟目标的瞬时位置。每个重点区域均具有一个或多个活动中心；时间推进时，活动中心会根据鸟群迁移、觅食、栖息和穿越飞行区等行为发生位移，热区半径和强度同步变化。当密度达到阈值时，区域风险由低→中→高变化，并触发右侧预警和处置提示。

当前原型使用预置关键帧模拟真实探测数据，后续可将 `frames` 替换为后端接口返回的时间序列或 WebSocket 实时数据。
