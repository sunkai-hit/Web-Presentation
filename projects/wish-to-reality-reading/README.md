# 从“显化”到习惯：愿望是怎么影响现实的？

以四本书为主线的 Web Presentation：从 20 世纪早期的“显化”思想出发，逐步进入动机心理学、习惯科学与叙事身份，讨论一个共同问题——人的愿望，究竟怎样一步步影响现实中的选择、行动与长期结果。

## 项目定位

- **主题**：从“显化”到习惯，理解愿望如何通过心理、行为、环境与自我叙事影响现实。
- **叙事方式**：作者背景 → 核心问题 → 故事 / 实验 → 作者目的 → 方法模型 → 四书整合。
- **表达原则**：不说教、不训练营化，不要求观看者现场反思或完成任务；以知识、故事和结构图推动理解。
- **当前版本**：v0.3.0 Prototype。

## 内容来源

1. Florence Scovel Shinn，《The Game of Life and How to Play It》：显化传统、愿望、语言、信念、潜意识与直觉。
2. Gabriele Oettingen，《Rethinking Positive Thinking》：积极幻想的边界、心理对照、WOOP 与 If–Then 计划。
3. Wendy Wood，《Good Habits, Bad Habits》：习惯科学、情境线索、摩擦力、奖励、重复与自动化。
4. Dan P. McAdams，《The Stories We Live By》：叙事身份、关键场景、主体性 / 联结、救赎与污染叙事。

## 视觉方向

- 米白纸感背景，深蓝 / 墨绿 / 暗红 / 暗金作为结构色。
- 书籍知识分享气质，避免卡通化、训练营化和儿童化。
- 每页保持一个中心问题，并通过卡片、流程图、对比图、脑图与案例强化理解。
- 复杂概念优先用“故事 / 实验 → 解释 → 结论”呈现。
- 节点内容要足够支撑讲解，不只是短标签。
