# 从“显化”到习惯：愿望是怎么影响现实的？

面向家庭读书分享场景的 Web Presentation。整体气质定位为“轻量大学选修课 / 通识读书分享”，避免说教、训练营或亲子互动课风格。

## 项目定位

- **主题**：从“显化”到习惯，理解愿望如何通过心理、行为、环境与自我叙事影响现实。
- **目标受众**：初中生及家庭共同观看，适合 25–35 分钟轻松分享。
- **叙事方式**：四本书、四种解释；知识型、故事化、结构图驱动。
- **当前版本**：v0.1.0 Prototype。

## 内容来源

1. Florence Scovel Shinn，《The Game of Life and How to Play It》：显化传统、愿望、语言、信念与未来图景。
2. Gabriele Oettingen，《Rethinking Positive Thinking》：WOOP、心理对照、愿望与现实障碍。
3. Wendy Wood，《Good Habits, Bad Habits》：习惯科学、情境线索、摩擦力、奖励与自动化。
4. Dan P. McAdams，《The Stories We Live By》：叙事身份、事实与解释、自我故事。
