# 内容说明

本项目是一份轻量通识读书分享，用四本书解释“愿望、行动、环境和自我故事”之间的关系。

主线：

- 从 manifestation / 显化这个流行词切入。
- 介绍 Florence Scovel Shinn 的早期思想：愿望、语言、信念、未来图景。
- 用 Gabriele Oettingen 修正单纯积极幻想：WOOP = 愿望 + 结果 + 障碍 + 计划。
- 用 Wendy Wood 补充习惯机制：情境线索、摩擦力、奖励、重复和自动化。
- 用 Dan McAdams 补充身份叙事：事实与解释、自我故事、身份更新。
- 最终整合为：未来图景 → 现实障碍 → 行为设计 → 环境习惯 → 真实证据 → 自我故事。

内容原则：

- 用书和作者的观点说话，而不是直接提出要求。
- 只提供一般案例，不预设听众必须改变什么。
- 保留知识点、作者背景和结构图，让内容有通识课质感。
- 不做现场填空、不做强互动、不做反思作业。
