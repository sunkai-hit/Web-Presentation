# PPT 页面详情稿

本稿完整版已随本次交付包提供，文件名为：`docs/05-PPT页面详情稿.md`。

页面设计原则：
- 16:9，米白纸感背景，深蓝、墨绿、暗金、酒红；
- 每页使用图片或图示，不再只堆文字；
- 每页固定保留“标题 + 核心解释 + 关键内容 + 页底结论”；
- 故事页和实验页采用“先讲发生了什么，再讲为什么重要”的结构；
- 机制页用流程图 / 系统图 / 对照矩阵表达关系；
- 每页配有演讲者备注，保证讲解内容不缺失。
