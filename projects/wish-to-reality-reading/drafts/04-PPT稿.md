# PPT 稿

本稿完整版已随本次交付包提供，文件名为：`docs/04-PPT稿.md`。

本稿按 32 页逐页写明：
- 这一页要解决的问题；
- 先讲什么、随后展开什么；
- 可使用的故事 / 实验 / 案例；
- 这一页最后落到什么结论。

特别处理：
- 不再用 WebPPT 的卡片式逻辑；
- PPT 每页包含演讲者备注，便于正式讲解；
- 第一、二、三、四本书均先介绍作者和书，再进入内容；
- 故事页和实验页均先讲故事/实验本身，再做现代解释和边界分析。

> 受当前 GitHub 连接器限制，大体量长稿与最终 PPT 二进制已放入可下载交付包；GitHub 保留框架、大纲、制作说明和项目状态。
