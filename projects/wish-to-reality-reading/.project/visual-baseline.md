# v1.0 视觉基线

## 基准

“电影院陈爆米花实验”demo 是主体知识页的最低视觉复杂度，而不是某个固定模板。

它体现的是：

- 明确叙事顺序；
- 一个可识别的主视觉场景；
- 不同区域承担不同信息角色；
- 实验/故事/机制不是一句话摘要，而是完整可读；
- 有对照、流程或因果关系；
- 有页底结论或生活迁移。

## 视觉方向

- 人文社科 / 心理学 / 读书分享 / 编辑设计；
- 米白纸感背景，深蓝、墨绿、暗红、暗金；
- 像一套设计过的杂志或公开课，而不是 Dashboard；
- 同一套视觉系统下允许页面结构显著不同；
- 作者页、故事页、实验页、流程页、时间线、矩阵、系统图应采用不同信息语言。

## v1.0 反例

以下情况直接返工：

- 4–6 个等高大卡片，每块只有一两行文字；
- 为了“填满页面”放大空容器；
- 用一个 grid 模板覆盖大多数页面；
- 内容稿丰富，但页面只留下摘要；
- 只有文字，没有真正承载关系的视觉元素。
