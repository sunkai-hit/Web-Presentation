# 视觉基线

## 风格

- 人文社科 / 心理学 / 读书分享气质。
- 米白纸感背景，配合深蓝、墨绿、暗红、暗金。
- 页面既保留视觉留白，又允许承载必要的故事、实验和概念解释。
- 避免卡通化、训练营化、儿童课件化和过强互动感。

## 版式

- 16:9 单屏演示。
- 每页保持一个中心问题，但不强行压缩成一句结论。
- 使用作者卡片、案例卡、流程箭头、对比矩阵、脑图节点等表达知识关系。
- 复杂概念优先用“故事 / 实验 → 解释 → 结论”呈现。
- 文字密度控制在投屏可读范围，重要内容通过层级、色块和留白组织。

## 已实现

- v0.1.0：基础 16 屏原型。
- v0.2.0：扩展为 22 屏讲义版，补充背景、故事、实验和作者目的。
- 单文件 HTML，无外部依赖。
- 键盘左右翻页与底部进度条。
