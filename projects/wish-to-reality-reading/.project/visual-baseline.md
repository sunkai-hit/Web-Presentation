# 视觉基线

## 风格

- 人文社科 / 心理学 / 读书分享气质。
- 米白纸感背景，配合深蓝、墨绿、暗红、暗金。
- 页面既保留视觉留白，又允许承载必要的故事、实验和概念解释。
- 避免卡通化、训练营化、儿童课件化和过强互动感。

## 版式

- 16:9 单屏演示。
- 每页保持一个中心问题，但不强行压缩成一句结论。
- 使用作者卡片、案例卡、流程箭头、对比矩阵、脑图节点等表达知识关系。
- 复杂概念优先用“故事 / 实验 → 解释 → 结论”呈现。
- 节点内容要足够支撑讲解，避免只有概念标签。
- 页面布局需覆盖上中下区域，避免内容只挤在顶部或居中漂浮。
- 对流程图类页面，节点内部至少包含“概念 + 解释 / 例子 / 讲解线索”中的两项。

## 已实现

- v0.1.0：基础 16 屏原型。
- v0.2.0：扩展为 22 屏讲义版，补充背景、故事、实验和作者目的。
- v0.3.0：扩展为 24 屏讲义版，重点增强流程图节点信息量与页面布局完整度。
- v0.3.0 拆分为 index.html、styles.css、app.js。
- 支持键盘左右翻页与底部进度条。
