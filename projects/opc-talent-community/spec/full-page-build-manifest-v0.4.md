## 关键产品交互
- Screen 05：四类角色切换业务路径。
- Screen 07：Hover 八阶段业务节点，查看参与方 / 平台动作 / 数据沉淀。
- Screen 08：人才档案 Tab、OPC 等级切换。
- Screen 11：点击“开始匹配”执行候选人匹配动画。
- Screen 12：点击项目阶段更新里程碑、任务、交付物和项目动态。
- Screen 13：初/中/高级 OPC 等级切换。
- Screen 16：人才 / 培训 / 企业 / 项目 / 成果运营视角切换。

## 数据使用规则
- 50 名学员、至少 5 个真实项目、至少 3 个基金储备项目来自现有社区工作计划。
- 其他进度、匹配分值、项目周期、课程进度、能力评分等仅作为产品演示示意，并在页面中明确标注“示意”。
