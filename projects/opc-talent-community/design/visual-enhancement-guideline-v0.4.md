# Web Presentation V0.4 图形增强执行规则

## 1. 已确认基线
- Screen 01 / 06 / 08 / 12 作为设计基线，本轮不改其主体布局和内容结构。
- 后续页面继续使用同一套 12 列 Grid、颜色、圆角、边框、状态标签和产品 UI 语言。

## 2. 本轮新增视觉原则
为解决“文字偏多、图片/图形偏少”的问题，剩余页面适度提高视觉元素比例，但不削弱产品内容。

建议单页视觉比例：
- 产品结构 / UI / 信息图：55%~65%
- 精炼文字：20%~30%
- 场景图 / 插画 / 本草与 AI 辅助元素：10%~20%

## 3. 页面增强策略
- Screen 02：真实揭牌照片 + 6/12/36 月阶段图形。
- Screen 03：五问题围绕平台核心的关系图，不做五张普通卡片。
- Screen 04：四类建设目标采用图形化能力区 + 专属图标。
- Screen 05：人物角色节点 + 中央平台关系图 + 角色视角切换。
- Screen 07：八阶段主链 + 三条数据回流弧线。
- Screen 09：四类课程图形 + 实训学习 UI + 人物实训场景插画。
- Screen 10：企业沟通场景 + 原始诉求到标准项目卡转化。
- Screen 11：能力匹配引擎 + 候选人才卡 + 动态匹配。
- Screen 13：四类评价来源 + OPC 三级成长阶梯 + 能力环。
- Screen 14：盾牌视觉 + 四阶段合规生命周期 + 风险分级。
- Screen 15：成果孵化漏斗 + 资源轮 + 路演场景插画。
- Screen 16：真实感运营后台 / 驾驶舱 UI。
- Screen 17：四类数据岛 + 中央产业人才数据底座网络。
- Screen 18：V1.0 核心圈层 + 后续增强云。
- Screen 19：6/12/36 月三阶段路线图 + 目标数字。
- Screen 20：五类价值节点 + 中央价值核心 + 本草线稿。

## 4. 图片与图形来源
- 揭牌现场：使用项目材料中的真实揭牌照片。
- 其他人物/企业/导师/路演场景：本轮优先使用自绘矢量插画，避免网络图片版权、风格不一致及加载依赖。
- 中医药元素：使用自绘本草线稿、叶片/植物抽象纹理。
- AI 元素：使用自绘节点、轨道、数据连线、匹配引擎等矢量图形。

## 5. 交互边界
交互用于帮助理解产品：
- 角色视角切换
- 业务节点解释
- 人才 Tab / OPC 等级切换
- 人才匹配动画
- 项目阶段切换
- 评价等级切换
- 运营视图切换

不加入无业务意义的持续闪烁、强粒子、过度 3D 或高频动画。
