# Content Baseline

## Current baseline

The current content baseline is the confirmed 20-screen leadership presentation structure represented by the migrated files in `spec/` and the stable `v0.4.1` implementation.

## Source of truth

Use the migrated `spec/` directory as the content and page implementation baseline. Do not rewrite confirmed business meaning during visual revisions unless the user explicitly changes the content baseline.

## Presentation structure

The stable version contains 20 screens and follows the confirmed narrative sequence from background and positioning through platform architecture, operating loop, core roles and workflows, governance/QA, release scope and expected value.

## Change rule

Content changes must be recorded in `revision-log.md` and reflected in page specifications before release artifacts are rebuilt.
