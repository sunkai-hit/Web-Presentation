# Visual Baseline

## Status

Visual baseline is confirmed for the stable `v0.4.1` release.

## Source of truth

Use the migrated `design/` directory together with the stable source under `prototype/full-v0.4.1/` as the visual baseline.

## Layout rules

- Target viewport: 1920 × 1080.
- One screen must fit within one viewport without vertical scrolling.
- Maintain balanced density: avoid both oversized empty margins and overfilled layouts.
- Preserve readable supporting text and keep total/detail relationships visually close.
- Existing locked key screens should not be redesigned during routine revisions unless explicitly requested.
