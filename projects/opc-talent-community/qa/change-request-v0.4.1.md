# Web Presentation V0.4.1 调整记录

本轮根据 2026-09-10 用户逐页审阅反馈调整，V0.4 保留不覆盖，新增 V0.4.1。

## 明确调整
1. Screen 02：替换为用户新提供的揭牌照片；右侧 6/12/36 月三个阶段框放大并收紧间距，小字同步放大。
2. Screen 09：重排为上方四个课程模块横向四列，中间业务路径全宽，下方课程 UI 与学习场景双栏等宽，总宽与中间流程条一致。
3. Screen 14：主体内容整体下移，重新平衡标题与流程区域的上下留白。
4. Screen 16：补齐项目运营看板内容；顶部后两项从空白数字改为“动态/累计”的非虚构运营状态表达。
5. 全局：除每页大标题外，提升小字、标签、正文、卡片说明、按钮等字号，优先保障现场汇报可读性。
6. 总分结构：Screen 01/03/05/11/13/15/17/18/20 的分部件向中心收拢并适当放大，减少“中心与外围脱节”的视觉问题。

## 版本原则
- 原 `prototype/full-v0.4` 和 `release/v0.4` 不覆盖。
- 新模块化源码放在 `prototype/full-v0.4.1/`。
- 新单文件离线版放在 `release/v0.4.1/`。
- 使用额外 `part-5.css` 和 `v0.4.1-patch.js` 实现本轮增量修订，减少对 V0.4 基线代码的侵入。
