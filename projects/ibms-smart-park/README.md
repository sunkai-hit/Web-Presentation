# IBMS 智慧园区运营中心原型

本项目用于验证 IBMS 园区管理大屏的视觉与交互方式，重点采用**轻量 2.5D SVG 空间模型 + 数据看板下钻**，避免引入重型 3D 引擎。

## 当前版本：v0.1.0

### 已完成
- 深蓝 / 蓝青智慧园区运营中心大屏；
- 5 栋园区建筑的轻量 2.5D 空间模型；
- 模型支持拖拽、滚轮缩放、按钮缩放和视角复位；
- 点击楼栋显示楼宇运行摘要；
- 支持“园区 → 楼宇 → 楼层”三级空间下钻；
- 楼层视图展示房间与设备状态点位；
- 左右 8 个数据看板均可点击下钻到详情弹窗；
- 底部支持“综合态势 / 安防消防 / 能耗环境 / 设备设施”主题切换；
- 全部使用原生 HTML / CSS / JavaScript，无 Three.js、ECharts 等外部依赖。

## 原型入口
`prototype/key-screen-v0.1.0/index.html`

## 交互说明
1. 点击任意楼栋查看楼栋摘要；
2. 点击“进入楼宇”进入楼层堆叠视图；
3. 点击任意楼层进入楼层平面视图；
4. 在中间模型区域拖动、滚轮缩放，或使用右上角缩放按钮；
5. 点击左右任一数据面板，打开对应模块下钻详情；
6. 点击底部主题按钮，切换空间模型中的业务点位关注层。

当前数据均为原型模拟数据，正式项目可替换为 IBMS / IoT / 能源 / 安防 / 门禁 / 停车等实时接口。
