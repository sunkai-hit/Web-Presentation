# IBMS 智慧园区运营中心原型

本项目用于验证 IBMS 园区管理大屏的视觉与交互方式。

## 当前版本：v0.2.0

本版已将中央园区从 V0.1.0 的 2.5D SVG 示意图升级为 **Three.js 轻量真实 3D 园区场景**，重点解决“模型效果与效果图差距大、不能旋转、空间交互不足”的问题。

### v0.2.0 已完成

- 中央区域改为真实 WebGL / Three.js 三维场景；
- 5 栋园区建筑全部为可交互 3D 对象；
- 支持鼠标左键拖动旋转、滚轮缩放、右键平移；
- 支持“旋转”按钮自动环绕园区；
- 支持点击建筑高亮并查看运行数据；
- 支持双击建筑自动聚焦；
- 支持“进入楼宇”与楼层选择、楼层相机定位；
- 支持安防、设备、能耗等空间点位随业务主题切换；
- 建筑加入楼层线、窗户发光、屋顶、底部光带、阴影等细节；
- 场景加入园区道路、中心广场、水景、绿化、路灯、停车区；
- 左右 8 个数据看板继续支持详情下钻；
- 页面仍保持轻量，不需要 BIM、Cesium、Unity 或 UE。

## 原型入口

- 当前版本：`prototype/key-screen-v0.2.0/index.html`
- 上一版本：`prototype/key-screen-v0.1.0/index.html`

## 中央模型交互

1. 左键拖动：旋转园区；
2. 鼠标滚轮：缩放；
3. 右键拖动：平移；
4. 点击建筑：选中、高亮、显示楼宇运行摘要；
5. 双击建筑：自动聚焦；
6. 点击“进入楼宇”：进入楼宇查看模式；
7. 选择 F1/F2...：定位对应楼层；
8. 点击“旋转”：开启/停止自动旋转；
9. 点击“⌂”：恢复园区总览；
10. 底部业务主题切换会联动三维点位。

> Three.js 与 OrbitControls 当前通过 jsDelivr CDN 动态加载。直接双击 HTML 可使用，但需要网络可访问 jsDelivr；正式交付时可再将 Three.js 依赖本地化到项目目录，做到完全离线运行。
