# 视觉与交互基线

- 总体定位：智慧园区数字孪生 + 企业工业控制台；
- 前端控件基线：参考 Edge-Gateway `prototype/edge-gateway-local-console-v0.7/index2.html`；
- 主背景：#041323；
- Header：#04111F；
- 主面板：#06182C；
- 二级面板：#071D33；
- 边框：#083253 / #0A3555；
- 主蓝：#03AFFE；
- 正常：#32D583；
- 警告：#FFB547；
- 告警：#FF5D6C；
- 控件：3~4px 小圆角、细边框、弱阴影、扁平深色面板、蓝色标题强调条；
- 避免：过度霓虹、复杂 HUD、影响 BIM 识读的装饰效果。

## 三维架构

- 园区总览：Three.js + Quaternius GLB，强调流畅鸟瞰和楼宇选择；
- 楼宇精细层：xeokit + XKT，强调 BIM 构件数量、对象拾取、楼层和大模型性能；
- 两个引擎共用同一套 Edge-Gateway 风格业务 UI，按空间层级切换，不同时渲染重场景。

## 数字孪生交互层级

1. 园区 LOD：楼宇选择、旋转、缩放、平移、聚焦；
2. 楼宇 BIM：构件级点击、IFC 类型/GUID/楼层信息；
3. 楼层：真实 IfcBuildingStorey 列表、抽屉拉出、整楼拆层；
4. 专业系统：消防 / 安防 / 暖通 / 电气，全楼或当前楼层透视；
5. 单设备：3D 定位、实时指标、趋势、事件、告警确认和工单动作。

当前专业设备层为交互验证数据；正式项目以真实 MEP/IFC 设备对象替换。
