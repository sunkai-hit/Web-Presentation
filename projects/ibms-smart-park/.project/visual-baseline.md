# 视觉基线

- 风格：智慧园区 / 数字孪生感 / 深色科技大屏；
- 主色：深蓝、蓝青、青色高光；
- 风险色：红色告警、橙色关注、绿色正常；
- 布局：左右业务看板 + 中央三维园区 + 顶部 KPI + 底部主题切换；
- 中央模型：Three.js 程序化低模园区，不依赖 BIM 精模；
- 三维细节：建筑体块、窗户灯光、楼层线、屋顶、底部光带、道路、广场、水景、绿化、路灯、停车区；
- 交互：OrbitControls 自由旋转 / 缩放 / 平移、建筑 hover、建筑点击高亮、双击聚焦、楼宇与楼层定位、自动旋转；
- 空间点位：安防、设施、能耗点位按业务主题切换；
- 内容密度：保持比原参考图更简洁，但中央模型必须成为视觉主角；
- 当前状态：V0.2.0 已从伪 2.5D 升级为真实 3D 场景。
