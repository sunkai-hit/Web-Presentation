# 视觉基线

- 总体定位：智慧园区 / 数字孪生 + 企业工业控制台；
- 前端控件基线：参考 Edge-Gateway `prototype/edge-gateway-local-console-v0.7/index2.html`；
- 主背景：#041323；
- Header：#04111F；
- 主面板：#06182C；
- 二级面板：#071D33；
- 边框：#083253 / #0A3555；
- 主蓝：#03AFFE；
- 正常：#32D583；
- 警告：#FFB547；
- 告警：#FF5D6C；
- 正文：#EAF7FF；
- 辅助文字：#91AFC6 / #66849C；
- 控件特征：3~4px 小圆角、细边框、弱阴影、扁平深色面板、蓝色左侧标题强调条；
- 按钮：普通按钮为 #071D33 + #0B4D78 边框，主按钮使用 #0872A9 → #075683 轻渐变；
- 避免：高饱和霓虹大面积发光、过多玻璃拟态、复杂 HUD 装饰；
- 布局：左右业务面板 + 中央三维园区 + 顶部 KPI + 底部业务主题；
- 中央模型：Three.js + Quaternius CC0 GLB；
- 交互：旋转 / 缩放 / 平移、建筑点击高亮、双击聚焦、自动环绕、业务主题点位切换；
- 当前状态：v0.3.2 已按 Edge-Gateway 视觉语言重构大部分前端控件。
