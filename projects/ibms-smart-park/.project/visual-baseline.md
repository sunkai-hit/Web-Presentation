# 视觉基线

- 风格：智慧园区 / 数字孪生感 / 深色科技大屏；
- 主色：深蓝、蓝青、青色高光；
- 风险色：红色告警、橙色关注、绿色正常；
- 布局：左右业务看板 + 中央三维园区 + 顶部 KPI + 底部主题切换；
- 中央模型：Three.js + 开源 CC0 GLB 模型，停止使用程序化 BoxGeometry 自建建筑；
- 建筑资产：Quaternius Downtown City MegaKit 的大/中/小型城市建筑；
- 环境资产：Quaternius 树木和灌木 GLB，结合自建道路、停车、广场、水景、路灯；
- 渲染：真实阴影、雾效、ACES Filmic、Bloom、高光和低强度发光；
- 交互：OrbitControls 自由旋转 / 缩放 / 平移、建筑点击高亮、双击聚焦、自动旋转；
- 空间点位：安防、设施、能耗点位按业务主题切换；
- 内容密度：保持左右看板简洁，让中央真实模型成为视觉主角；
- 当前状态：V0.3.0 已切换到成熟开源模型资产路线，视觉效果待用户确认。
